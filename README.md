# בר שלו-נתן · אתר תדמית

אתר סטטי בעברית ובאנגלית (HTML, CSS ו-JS בלי תלויות ובלי שלב בנייה), מוכן לאחסון ב-GitHub Pages.

## מבנה

```
index.html              העמוד בעברית (מימין לשמאל)
en/index.html           העמוד באנגלית (משמאל לימין)
assets/css/style.css    עיצוב משותף. הטוקנים (צבעים, פונטים) בראש הקובץ
assets/js/main.js       טופס יצירת קשר, תצוגה מקדימה של ההודעה, טיקר ושעון.
                        כל הטקסטים של הטופס בשתי השפות נמצאים ב-STRINGS
assets/img/             התמונה של בר (bar-640/1280 ב-JPG וב-WebP),
                        favicon ותמונות שיתוף (og.png בעברית, og-en.png באנגלית)
relay/                  ממסר אופציונלי לשליחה אוטומטית דרך WaSender
```

## העלאה ל-GitHub Pages

1. ב-GitHub: **Settings → Pages**.
2. תחת **Build and deployment** בוחרים **Deploy from a branch**.
3. בוחרים את הענף שבו נמצא האתר ואת התיקייה `/ (root)`, ושומרים.
4. אחרי דקה-שתיים האתר יעלה בכתובת `https://hagynwa.github.io/bar-site/`, והגרסה האנגלית ב-`https://hagynwa.github.io/bar-site/en/`.

אם עוברים לדומיין משלכם, מעדכנים את הכתובות בתגיות `canonical`, `alternate` ו-`og:` בראש שני הקבצים.

## שתי השפות

כל שפה היא עמוד נפרד, עם מתג שפה בכותרת העליונה ותגיות `hreflang`, כך שגוגל מציג לכל גולש את הגרסה המתאימה. הטקסטים באנגלית נכתבו מחדש ולא תורגמו מילה במילה, ולכן כשמשנים טקסט בעברית כדאי לעדכן גם את המקבילה האנגלית. ההודעה שנשלחת לבר בוואטסאפ נכתבת בשפה של העמוד שממנו הגולש פנה.

## עדכונים נפוצים

- **רשתות חברתיות**: כל קישור מופיע בשני מקומות בכל עמוד (באזור יצירת הקשר ובפוטר), וגם ברשימת `sameAs` שבראש כל קובץ.
- **מספר וואטסאפ**: `CONFIG.whatsapp` ב-`assets/js/main.js`, וגם בקישורי `wa.me` ובמספר המוצג בשני העמודים.
- **המסלול המקצועי**: כל שורה בגרף מוגדרת עם `--s` (התחלה) ו-`--e` (סיום) כשנים עשרוניות, למשל `2018.45` הוא יוני 2018. הגרף מצויר בקנה מידה לפי הערכים האלה.

## טופס יצירת הקשר

ברירת המחדל עובדת בלי שום הגדרה: הגולשים ממלאים את הטופס, ולחיצה על "שליחה בוואטסאפ" פותחת את וואטסאפ אצלם עם הודעה מסודרת לבר. נשאר להם רק ללחוץ "שלח".

### שליחה אוטומטית דרך WaSender (אופציונלי)

אם רוצים שההודעה תגיע לבר בלי שהגולשים יצטרכו לפתוח וואטסאפ, אפשר לשלוח דרך [WaSender](https://wasenderapi.com). מפתח ה-API של WaSender לא יכול לשבת באתר סטטי (כל מי שגולש יראה אותו), ולכן הוא נשמר בממסר קטן ב-Cloudflare Workers:

1. ב-WaSender: יוצרים Session ומחברים אליו מספר וואטסאפ. **המספר הזה הוא השולח**, לכן עדיף מספר נפרד (למשל מספר עסקי) ולא המספר של בר. מעתיקים את ה-API Key של ה-Session.
2. ב-Cloudflare: **Workers & Pages → Create → Worker**, ומדביקים את התוכן של `relay/wasender-worker.js`.
3. ב-**Settings → Variables and Secrets** של ה-Worker מוסיפים:
   - `WASENDER_API_KEY` (כ-Secret): המפתח מ-WaSender
   - `TO_NUMBER`: `+972503337074`
   - `ALLOWED_ORIGINS`: `https://hagynwa.github.io`
4. מעתיקים את כתובת ה-Worker ומדביקים אותה ב-`CONFIG.relayUrl` שב-`assets/js/main.js`.

מרגע זה הטופס שולח דרך הממסר. אם השליחה נכשלת, הגולשים מקבלים קישור לשלוח את אותה הודעה ישירות מוואטסאפ, כך שאף פנייה לא הולכת לאיבוד.

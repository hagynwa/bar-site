# סרטון תדמית

סרטון של 25 שניות (‎1920×1080, ‏25 פריימים לשנייה) באותה שפה עיצובית של האתר: פסי צבע של בדיקת שידור, עלייה לשידור עם כתובית שם, המסר, התחומים, המסלול וכרטיס סיום.

## רינדור

```
node promo/render.mjs            # יוצר את promo/out/bar-promo.mp4
```

נדרשים Node, ‏ffmpeg ו-Playwright (‏`npm i playwright`). הקומפוזיציה עצמה נמצאת ב-`promo.html`, והסאונד נוצר בתוך `render.mjs`.

## הוספת הקריינות של בר

```
node promo/narration.mjs <קובץ-או-קישור> <התחלה> <סיום>
node promo/render.mjs
```

למשל `node promo/narration.mjs https://youtu.be/... 1:23 1:27`. הקטע צריך להיות באורך של כ-4 שניות. הוא ייכנס לסצנת העלייה לשידור, המוזיקה תרד מתחתיו, ומד המיקרופון שעל המסך יגיב לקול שלה. קובץ הקריינות והפלט לא נשמרים במאגר.

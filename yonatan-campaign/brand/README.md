# מיתוג

## לוגו "עוד קצת ילדות"

נבחרה אפשרות ב': שמש בעפרון שעולה מעל גבעה ירוקה, עם כתב היד של הסדרה (Playpen Sans Hebrew 800).
שלוש האפשרויות שהוצעו נמצאות ב-`logo-options.html` וב-`logo-options.png`.

| קובץ | מתי משתמשים |
|---|---|
| `logo/logo-stacked.svg` / `.png` | הלוגו הראשי: סמל מעל הכיתוב. לכרטיסי סיום, לכותרת האתר, לפוסטים |
| `logo/logo-horizontal.svg` / `.png` | שורה אחת, כשהמקום צר: פינת הסרטון, באנרים |
| `logo/*-white.*` | על רקע כהה |
| `logo/icon.svg` / `.png` | הסמל לבד על ריבוע בצבע נייר: תמונת פרופיל, favicon |
| `logo/icon-transparent.*` | הסמל לבד, רקע שקוף |
| `logo/parts/` | שכבות להנפשה (שמש, גבעות, כיתוב) ו-`layout.json` |

- **קבצי ה-SVG הם וקטור נקי.** הכיתוב הומר לקווי מתאר, והקווים הלא-מושלמים של כתב היד "אפויים" לתוך הצורות עצמן. לכן הקבצים נפתחים אותו דבר בדפדפן, ב-Canva, ב-Illustrator ובבית דפוס, גם בלי הגופן.
- **קבצי ה-PNG:** רקע שקוף, ברזולוציה פי 3. האייקון ב-1024×1024.
- **בנייה מחדש:** `python3 brand/build_logo.py` (נדרשים fonttools ו-uharfbuzz).
- **צבעים:** אותם צבעים של לוגו ההנהגה: כחול כהה `#001A3F`, ירוק `#699F03`, ירוק עלה `#B5D96E`, שמש `#FECC0C`.

## לוגו הנהגת ההורים

- `logo-original.png`: הקובץ המקורי שהתקבל.
- `logo-transparent.png`: רקע שקוף, חתוך.
- `logo-640.webp`: לרשת.

בכרטיס הסיום של הסרטונים הוא מופיע מתחת לכיתוב "מטעם".

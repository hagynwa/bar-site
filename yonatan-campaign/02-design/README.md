## משותף לכל הכיוונים

- הסיפור החזותי: המסך כהה וקר, הילדות צבעונית.
- פתיח זהה (כשנייה, אחרי ההוק): מסך שחור "נכבה" ונפתח לצבע + "עוד קצת ילדות".
- סגיר זהה: השם, הלוגו, הפניה לאתר.
- נתונים: מספר אחד גדול בכל פריים, באותו פונט כמו שאר הטקסט. אם יש איור נתונים, הוא בצורת הדגשה (צבע אחד לנתון, אפור/ירוק לשאר), עם מקרא כתוב, ושורת מקור קבועה.

## הכיוונים

- **א · מחברת**: דף משבצות, כתב יד (Playpen Sans Hebrew) + Rubik למספרים. חם וביתי, פחות עוצר גלילה.
- **ב · גדול וברור**: רקע כחול כהה, Rubik 900 ענק, צהוב שמש להדגשה. עוצר גלילה, קר יותר.
- **ג · החצר** (המלצה): העולם של הלוגו בגזרות נייר: גבעות, שמש, בית. גרסת יום וגרסת לילה. Fredoka. ממשיך את הלוגו ומספר את סיפור הקמפיין.
